tscircuit standalone / build milestone

Three circuits built offline.

The compiled executable evaluates local circuits, routes the PCB, and produces Circuit JSON, SVG previews, and diagnostics. These outputs were generated with the pinned evaluator and renderer in the standalone repository.

The examples exercise the runtime. The RP2040 fixture omits flash, crystal, USB implementation, and full per-pin decoupling. Retained warnings appear below each circuit. Use the tabs and zoom slider to inspect the drawings.
